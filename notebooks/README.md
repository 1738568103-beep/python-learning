# Titanic Survival Analysis

This is my first Python data analysis project.

## Project Goal

The goal of this project is to explore the Titanic passenger dataset and investigate factors associated with passenger survival.

## Questions

- What was the overall survival rate?
- Did sex affect survival?
- Did passenger class affect survival?
- Which columns contain missing values?

## Initial Findings

- The overall survival rate was approximately 38%.
- Female passengers had a higher survival rate than male passengers.
- First-class passengers had a higher survival rate than third-class passengers.
- The Cabin and Age columns contained many missing values.
